# LICENSES directory

This directory contains the license texts required by the [REUSE](https://reuse.software/) specification
and [SPDX](https://spdx.org/) standard for the Siconos project.

It collects all license files for all SPDX tags presents in the current repository:
- Siconos license
- All licenses for external dependencies (mostly in externals)

It means one should be able to run 'reuse lint' with success.

Some specific cases are handled thanks to the file REUSE.toml.
